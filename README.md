# OmniDock

一个 Windows 桌面悬浮窗，实时显示 Mirasim 用量：占比、已用 / 限额、以及距离重置的倒计时。

- **毛玻璃背景**，无边框、可整体拖动、置顶
- **数字滚动**（里程表效果），只有变化的那一位会滚
- **速率预测**：按窗口内的平均消耗速度推算会不会在重置前用光。跨天的窗口要等样本
  攒满一整个昼夜才下结论——刚重置那几个小时采到的全是连续工作时段，拿它外推等于
  假设人接下来几天不吃不睡；在那之前只并排显示当前强度和匀速线（额度 ÷ 窗口长度）
- **缓冲条**：用量条上的半透明段是按当前速率预计到重置时会用到的位置，
  它和实色段之间的差就是预计还会消耗的量
- **额度告警**：水位过高或预计撞墙时脉冲提示
- **托盘图标**：把占比画成进度环，窗口收起也能扫一眼
- **可配置**：界面缩放、窗口宽度、玻璃厚度、刷新间隔（0.5～60 秒）、强调色、置顶、
  内置计时器、告警、开机自启、关闭到托盘
- 窗口位置和设置自动记住

## 运行环境

- Windows 10 1803 及以上（毛玻璃依赖 `SetWindowCompositionAttribute`）
- [.NET 10 SDK](https://dotnet.microsoft.com/download) 或对应的桌面运行时

## 构建

```powershell
dotnet build -c Release
.\bin\Release\net10.0-windows\OmniDock.exe
```

## 数据来源

用量走 **账号 token 直连上游**：`GET {上游地址}/v1/limits`，认证头 `Authorization: Bearer <token>`。
上游地址默认 `https://relay.mirasim.ai`，可以在设置面板改；留空表示不走直连、只用本地代理。

token 不用手填——程序直接从本机 Mirasim 的配置里解出来：

| 文件 | 内容 |
|---|---|
| `~/.mirasim/setting.json` | `auth.token`：`"mrs1:" + base64(iv ‖ tag ‖ 密文)`，AES-256-GCM |
| `~/.mirasim/secret.key` | 主密钥，DPAPI（当前用户）保护过的十六进制串 |

两样都能被当前用户解开，所以**不需要会话环境变量、也不要求 Mirasim 正在运行**。Mirasim 自己续期
之后会把新 token 写回同一个位置，程序按「mtime + 长度」判新旧，续期能自动跟上；上游回 401 时还会
丢掉缓存重新解一次。

直连是主路径，因为它不受代理重启影响。代理是**回退路径**：它的入口形如
`http://127.0.0.1:<随机端口>/<43 位随机路径>`，**那段路径本身就是凭据**——带上它即使不带 token 也能通，
少了它一律 401。端口和路径每次代理启动都换新，且只注入会话环境变量 `ANTHROPIC_BASE_URL`、不落盘，
所以回退时按这个顺序找：

1. 会话环境变量 `ANTHROPIC_BASE_URL`（从带环境的会话里启动时）
2. 自己存下的入口（`settings.json` 的 `AuthBaseUrl`，双击和开机自启全靠它）
3. 上次成功的端点缓存（同一次代理运行期间有效）
4. 反查代理进程监听的回环端口（拼不出路径，但能区分「代理在跑」和「进程没了」）
5. 从其它 CLI 会话的命令行里捞（见下）

前四条都建立在「之前见过」上，代理一重启就全部作废。第 5 条是唯一能凭当下机器状态重新发现的：
代理会把入口注入它启动的每个 CLI 会话，有些 CLI 会把它展开在自己的命令行上，于是查一下就能
拿到当前有效的入口。命令行是进程的公开信息（任务管理器就看得到），取它**不需要读别人的内存**；
实现上只认「回环地址 + 至少 20 字符路径」这个形状，别的一概不看也不留。这一步要一秒多，所以
排在最末尾，且成功后会存进配置，30 秒内不重复扫。

成功用上的入口一律存回 `settings.json`，下次冷启动直接走快路径。要让它跟着代理自动续期，可以用
Claude Code 的 hook 把 `ANTHROPIC_BASE_URL` 写进配置——挂 `SessionStart` 只在开新会话时续一次，
挂 `UserPromptSubmit` 则每次发消息都续，代理重启后基本无感。运行中的实例会盯着配置文件，
一改就立刻重连，不必等重试退避，也不用重启。手填也行，见设置面板的「入口地址（回退）」。

旧版代理用 header 里的 `ANTHROPIC_AUTH_TOKEN` 认证，这条路径仍然保留：入口地址有效时代理会
忽略 header，所以存着过期 token 不影响。

拿不到数据时窗口会显示提示，并按退避间隔重试，不会一直空转。状态栏会标出这一拍的数据来自哪条路：
`· 直连` 是直连上游，`· 代理` 是回退到本地代理。两条都不通时，提示里报的是直连给出的原因
（没登录 / token 过期 / 上游连不上），因为它比「找不到本地代理」更接近根因。

倒计时默认由本地每秒推进（**内置计时器**）。把它关掉，倒计时就只在收到响应时
按 `reset_at` 重算——显示的完全是服务端确认过的值，代价是更新粒度变成刷新间隔。

## 存在哪

`%LOCALAPPDATA%\OmniDock\` 下三个文件：

| 文件 | 内容 |
|---|---|
| `settings.json` | 界面设置、窗口位置、上游地址、回退用的入口地址与 token |
| `endpoint.txt` | 上次成功的代理端点，省一次端口反查（只在回退路径上用到） |
| `usage-history.json` | 用量历史：每个整点记一次各窗口的已用量，留两周 |

用量历史是为了让预测早点可用。它不随额度窗口重置而清零，所以 7 天窗口每周重置之后，
上一周攒下的节奏立刻能接着用，不必再空等一天。历史不足一天时才退回上面说的匀速线对照。
把鼠标停在预测那行字上，会说明这次的推算依据——包括一天里实际有多少比例的时间在消耗。

一天 24 条、留两周也就几十 KB。删掉它只会让预测退回「等窗口自己走满一天」，不影响其它功能。
